# Учебный RAG-проект: консультант по уходу за ювелирными изделиями

Этот проект показывает, как устроен настоящий RAG (Retrieval-Augmented
Generation) — в отличие от твоего первого бота, где весь каталог целиком
засовывался в system prompt, здесь модель получает только релевантные
куски базы знаний, найденные через векторный поиск.

## Структура проекта

```
rag_project/
├── knowledge_base/       ← текстовые файлы базы знаний (5 статей)
├── build_index.py        ← шаг 1: строит векторную базу из текстов
├── rag_bot.py             ← шаг 2: ищет релевантные куски и спрашивает Claude
├── requirements.txt
├── .env.example
└── README.md
```

## Установка

1. Скопируй папку `rag_project` к себе на компьютер.
2. Установи зависимости:
   ```
   py -m pip install -r requirements.txt
   ```
   (первая установка `sentence-transformers` может занять несколько минут —
   библиотека тяжёлая)
3. Скопируй `.env.example` в `.env` и впиши туда свой `TOOKEN_API_KEY`
   (тот же самый ключ, что используешь в основном боте).

## Запуск

**Шаг 1 — построить базу знаний (один раз):**
```
py build_index.py
```
При первом запуске скачается модель эмбеддингов (~90 МБ) — это нормально,
дальше она работает офлайн. В консоли появится "Готово!" и число
проиндексированных кусков текста.

**Шаг 2 — запустить бота:**
```
py rag_bot.py
```
Задавай вопросы, например:
- "Как чистить золотое кольцо?"
- "Можно ли мыть жемчуг с мылом?"
- "Что означает проба 585?"
- "Как понять свой размер кольца?"

Бот покажет в консоли, какие фрагменты базы он нашёл под вопрос —
это специально оставлено видимым (`verbose=True` в `ask_rag`),
чтобы наглядно видеть, как работает поиск. В реальном продукте это
обычно скрывают от пользователя.

## Что можно попробовать дальше (для углубления)

- Добавь свою статью в `knowledge_base/` и перезапусти `build_index.py` —
  посмотри, начнёт ли бот её находить.
- Поменяй `TOP_K` в `rag_bot.py` (сейчас 3) — посмотри, как меняется
  качество ответа при 1 или при 5 найденных кусках.
- Задай вопрос, ответа на который в базе точно нет ("Как отремонтировать
  часы?") — проверь, что бот честно скажет "не знаю", а не выдумает.
- Попробуй свою реальную базу товаров вместо учебной — просто замени
  файлы в `knowledge_base/`.
